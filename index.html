FPGA-Based Real-Time Temperature Monitoring

Project Title

FPGA-Based Real-Time Temperature Monitoring and Predictive Thermal Management System Using Intelligent Sensor Interfaces

Project Overview

This project is designed to monitor temperature in real time using an FPGA-based system and intelligent sensor interfaces. The system helps in monitoring temperature and providing predictive thermal management.

Vivado Project

The project was developed and tested using AMD Xilinx Vivado. The Vivado project files are available in this repository.
